# AI 学习计划 · 真·云端同步版

一个零依赖的 Node.js 同步后端 + 单文件前端，让「3 个月 AI 学习计划器」在**手机和电脑之间实时共享学习进度、笔记和操作历史**。

> 原需求：抖音带货直播操盘手（敏感肌护肤类目）的 72 天交互式 AI 学习路径（吴恩达 / 李宏毅 / 李沐 / 卡卡西），要能跨设备云端同步。

---

## 功能特性

- **跨设备实时同步**：手机和电脑打开同一「同步链接」，进度/笔记/历史自动对齐（30 秒拉取 + 1 秒防抖推送）
- **防冲突合并**：多设备同时改，用「并集 + 去重」合并，不会互相覆盖
- **离线降级**：云端连不上时自动退回本机缓存，恢复后自动补传
- **同步码机制**：一个短码（`sync=xxxx`）就是你的云端身份，复制链接即分享
- **零依赖后端**：Node 内置模块（`http`/`fs`/`path`），`npm install` 几乎秒过
- **一键部署**：配合 `render.yaml` 可在 Render 免费托管，永久 24/7 在线

## 目录结构

```

├── server.js          # 零依赖同步后端（REST /api/* + 静态托管）

├── render.yaml        # Render 一键部署配置
├── DEPLOY.md          # 详细部署教程（Render / Railway / Fly.io / 自有服务器）

└── data/              # 运行时按同步码生成 <码>.json（自动创建，已 gitignore）
```

## 本地运行

```bash
cd cloud-sync
node server.js
# 打开 http://localhost:3000
```

首次打开会自动生成一个同步码并写入 URL（`?sync=xxx`）。把链接复制到手机，即可跨设备同步。

## 一键部署（Render，免费，永久在线）

**方式 A：按钮部署**
1. 把本仓库推到 GitHub
2. 打开 https://render.com → New → Web Service → 连接该仓库
3. Build Command 填 `npm install`，Start Command 填 `node server.js`
4. 直接 Deploy，拿到形如 `https://ai-planner-xxx.onrender.com` 的永久网址

**方式 B：render.yaml 部署**
1. 推到 GitHub 后，在 Render 选择「Blueprint」或 New → Web Service 时它会自动识别 `render.yaml`
2. 点部署即可，配置已写死在文件里

详细图文教程见 `DEPLOY.md`。

## 同步用法（部署后或本地都适用）

| 场景 | 操作 |
|------|------|
| 手机↔电脑同步 | 在一台点顶部「复制同步链接」→ 另一台用该链接打开 |
| 手动立即同步 | 点「立即同步」按钮（主动 pull 一次云端） |
| 输入他人的同步码 | 点「输入同步码」粘贴短码或完整链接 |
| 独立后端（非同源） | 在链接后加 `?api=https://你的后端/api` |
| 查看状态 | 顶部状态条：🟢 已同步 / 🟡 同步中 / ⚪ 离线仅本机 |

## 部署注意事项

- **免费层冷启动**：Render 免费 Web Service 在闲置 15 分钟后会休眠，首次访问需等几秒唤醒，属正常现象。
- **数据存服务器文件**：每个同步码对应 `data/<码>.json`，存于运行实例的文件系统。免费实例重启/重建可能清空 `data/` —— 重要学习数据建议定期「导出备份」（可在前端加导出按钮，或手动备份 `data/` 目录）。
- **隐私**：同步内容（学习进度、笔记）以明文 JSON 存于服务器，请勿放入敏感信息；如需更强隔离，可改用带鉴权的存储或自有服务器。
